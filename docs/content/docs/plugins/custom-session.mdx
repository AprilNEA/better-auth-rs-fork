---
title: Custom Session
description: Transform public session responses with typed application context.
---

Register `CustomSessionPlugin::new(callback)` with an implementation of `CustomSessionCallback<YourSchema>`. The asynchronous callback receives `CustomSessionInput`, the request, and `AuthContext<YourSchema>`. Return the response as a JSON value. `input.data` contains the public user and session; `input.needs_refresh` carries the optional deferred-refresh signal. The context provides typed store access and configured plugin extensions.

The callback input uses `NativeSessionData` and retains native `FieldValue` values from the session service, including Date objects, own undefined properties, relationship arrays, and shared object references in additional fields. `input.data.field_value()` shares the complete native root. Read current properties with `input.data.session_property("token")?` and `input.data.user_property("id")?`; use `session_view()` and `user_view()` only for explicit Rust views. The callback's `serde_json::Value` return type is an explicit JSON output boundary. Returning `serde_json::to_value(input)?` encodes dates and omits undefined object properties. A global after hook that replaces a device-session list runs before the list customization callback; the callback receives that replacement.

The plugin overrides `GET /get-session` regardless of its registration order relative to `SessionManagementPlugin`. A successful transformation preserves the session response headers and cookies. A missing session returns `null` without calling the callback. As in upstream Better Auth, an error reading the underlying session also returns `null`. Callback errors propagate. The override accepts only `GET`, including when deferred session refresh is enabled.

Call `.mutate_list_device_sessions(true)` to apply the callback to each result from `MultiSessionPlugin`. The callbacks run concurrently and the output preserves list order. An error fails the response while other callbacks continue, matching upstream `Promise.all`. Each task retains the endpoint runtime, request metadata, tracing context, and transaction scope. Runtime URL assignments remain visible to sibling callbacks and store hooks after the first error.

The callback changes the public response only. Internal authentication, persisted sessions, and cookie-cache contents retain their original shapes. Return `serde_json::to_value(input)?` with added application fields to preserve the default response fields.
